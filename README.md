# Lidea Girişim Programı 3. Dönem — MVP
Next.js App Router + TypeScript + Tailwind CSS.

## Kurulum
```bash
npm install
npm run dev
```
Tarayıcı: http://localhost:3000

## İçerik
- Responsive landing page
- Hero / Program / Süreç / SSS / CTA
- `/basvuru` başvuru formu
- `/api/applications` demo POST endpoint
- Vercel uyumlu yapı

> Not: Bu MVP özgün bir demo arayüzüdür. Resmî 3. dönem tarihleri, logolar, mentorlar ve program koşulları doğrulanarak eklenmelidir.
